# UI Engineering

Skills for analyzing, evaluating, documenting, testing, and improving user interfaces, interaction behavior, product flows, reactive code quality, evergreen UI documentation, and UX implementation details.

## Skills

- **document-ui-flows** - Analyze an application UI and produce a feature/flow diagram plus text describing each flow, user story, behavior, states, and open questions.
- **enforce-reactive-ui-quality** - Keep UI code reactive, precise, cohesive, and split into small files with clear responsibilities and minimal over-rendering.
- **enforce-testable-ui-flows** - Ensure discovered UI flows and stories can be covered by small backend-free tests through repository/service interfaces, fakes, fixtures, dependency injection, and Playwright-generated documentation artifacts.
