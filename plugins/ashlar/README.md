# ashlar

Skills for using [ashlar](https://github.com/JedimEmO/ashlar) in a Bevy game: procedural buildings
and PBR materials authored in Rust, baked by a content step, and loaded with `AshlarPlugin`.

## Skills

- **ashlar-game-setup** — Content step vs game crate, dependencies and features, `AshlarPlugin`, asset layout, levels of detail, WebGL2, load errors
- **ashlar-building-authoring** — Parts, elements, cutters, instances and sockets, collision proxies, rooms and portals, merge groups, LOD-friendly authoring
- **ashlar-game-materials** — The default material library, game-specific definitions, per-instance variety, bake resolution, baked grass and moss
- **ashlar-runtime** — Physics colliders, room lookup, storey cutaways, damage, and frame time with many pieces (WebGL2, phones)
