# Rust API Stack

Skills for building type-safe services with Rust API Stack (RAS): REST, JSON-RPC, file, and WebSocket APIs via macro-driven code generation.

- Documentation: <https://jedimemo.github.io/rust-api-stack/>
- Repository: <https://github.com/JedimEmO/rust-api-stack>

## Skills

- **ras-setup** — Project creation, workspace config, dependency management
- **ras-api-design** — REST endpoints, JSON-RPC methods, macro syntax, OpenAPI generation
- **ras-security** - Authentication, authorization, JWT, OAuth2, permission groups, permission manifests
- **ras-best-practices** - Observability, error handling, generated clients, metrics, service-to-service communication
